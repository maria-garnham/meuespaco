# 📚 Meu Espaço — Gerenciador de Estudos

> Aplicativo mobile para organização e acompanhamento dos estudos.

---

## 📌 Sobre o projeto

**Meu Espaço** é uma aplicação desenvolvida em **React Native** com o objetivo de auxiliar estudantes na organização dos conteúdos que precisam ser estudados.

A aplicação permite criar **matérias**, adicionar **assuntos dentro de cada matéria** e acompanhar quais conteúdos já foram estudados por meio de marcações de conclusão.

A ideia principal é transformar uma simples lista de matérias em uma estrutura organizada:

**Matéria → Assuntos → Acompanhamento do progresso**

---

## 🎯 Objetivo

O projeto foi desenvolvido com o objetivo de oferecer uma maneira simples e intuitiva de organizar uma rotina de estudos.

Em vez de manter apenas uma lista de matérias, o usuário pode detalhar o conteúdo de cada uma.

### Exemplo

Uma matéria como:

**História**

pode possuir:

- Revolução Russa
- Revolução Cubana
- Primeira Guerra Mundial
- Era Vargas
- Guerra Fria

  Exemplo:

História

2 de 5 assuntos concluídos

☑ Primeira Guerra Mundial
☑ Era Vargas
☐ Revolução Russa
☐ Revolução Cubana
☐ Guerra Fria

Cada assunto pode ser marcado individualmente conforme for estudado.

---

## ✨ Funcionalidades

### 📚 Gerenciamento de matérias

O usuário pode:

- Adicionar uma nova matéria;
- Visualizar as matérias cadastradas;
- Selecionar uma matéria para acessar seus conteúdos;
- Excluir uma matéria;
- Visualizar o progresso dos estudos de cada matéria.

### 📝 Gerenciamento de assuntos

Dentro de cada matéria, o usuário pode:

- Adicionar novos assuntos;
- Visualizar os assuntos cadastrados;
- Marcar um assunto como estudado;
- Desmarcar um assunto;
- Excluir um assunto.

### 📊 Acompanhamento do progresso

O aplicativo calcula automaticamente a quantidade de assuntos concluídos.
